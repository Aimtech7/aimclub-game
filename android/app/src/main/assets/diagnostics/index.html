Ready for game night?

Use this page on each phone. These checks do not prove that two phones can exchange real audio/video or that installation works. Nothing is recorded or uploaded as a report automatically.

Browser capabilities

The media test asks permission, then immediately stops its tracks. The relay test uses your saved room connection and contacts the configured relay; it does not start a call or record media.

Two-phone checklist
  1. On each phone, open the HTTPS site and confirm adult access.
  2. Create a room on phone A, share its link, join on B, press Ready and start.
  3. Compare prompts, chat messages, answers, scores and spectator permissions.
  4. Join voice/video, speak both ways, mute, disable camera, leave and rejoin. Repeat on different networks.
  5. Install the PWA; wait for Offline ready, turn off internet and open Friends.
  6. Reconnect, resume a room, rotate the screen and check the exit control.
  7. For the Android APK, also test camera permissions, JSON import, backups and calendar downloads.
Keep the report private if you share it for support. It excludes names, room codes, reconnect tokens, IP addresses and relay credentials.
